## 产品功能

试听课堂表现和家长反馈记录。

- 主要输入：试听课程目标、课堂环节、学生表现、教师观察、家长问题和后续建议
- 主要输出：课堂观察记录、学习表现摘要、家长反馈要点、匹配建议和待确认项
